# Kerala SCERT Obsidian Knowledge Vault

This `SCERT` directory is the vault root. Open this folder in Obsidian and start at [[HOME]].

## Status and scope

Class 9 English Medium is complete for all common subjects and current textbooks/activity books available from the Samagra portal. Choice-based language-reader offerings are documented in [[Class 9/English Medium/CATALOG_SCOPE]]. The 2019 ICT Part I source is preserved separately as a legacy file; the current 2025 Part I is processed. Other classes and mediums have not been started.

## Folder architecture

`Class 9/English Medium/<Subject>/` contains the subject overview, chapter notes, substantial concept notes, definitions/formulas where useful, exercises/activities, and one Canvas per textbook. `_Source PDFs/` retains original PDFs locally. `scripts/` contains reproducible build and validation utilities. `.review/` contains temporary page renders and is excluded from Git.

## Use and source files

Open `HOME.md` in Obsidian. Canvas cards open individual Markdown notes; graph links reflect curricular relationships. Original PDFs are kept locally and excluded from Git because redistribution permission was not established. See the validation report before relying on completeness claims.
