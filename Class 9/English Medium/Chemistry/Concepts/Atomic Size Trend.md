# Atomic Size Trend

Atomic radius expresses atomic size as distance from nucleus centre to the outermost electron shell. Down a group, added shells outweigh increased nuclear charge, so atoms become larger. Across a period, shell count stays fixed while nuclear charge rises, pulling outer electrons closer; size generally decreases. The textbook introduces inner-shell screening as a reason nuclear attraction on outer electrons is reduced.

**Textbook reference:** Chemistry Standard IX Part I, printed pp. 37-39.
