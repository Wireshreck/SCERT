# Periodic Table - Assessment and Activities

Exercises practise configurations, group/period/family identification, noble-gas stability, relative atomic size, periodic-table positions and deriving real element symbols from placeholder grids and mass/neutron data. Extended work includes a scientist biography, table model and Kalzium-supported element chart.

**Textbook reference:** Chemistry Standard IX Part I, printed pp. 40-42.
