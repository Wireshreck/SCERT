# Oxidation Number Sum Rule

For a neutral compound, Σ oxidation numbers = 0. In an element in its uncombined state, oxidation number = 0. Use known values such as H=+1 and O=−2 to solve for an unknown.

**Textbook reference:** Chemistry Standard IX Part I, printed pp. 79-81.
