# Atomic and Neutron Counts

A = Z + N; N = A − Z. Here A is mass number, Z is atomic number (protons), and N is neutron count. For a neutral atom, electron count = Z.

**Textbook reference:** Chemistry Standard IX Part I, printed pp. 18-20.
