# Representative Reaction Equations

Examples shown in the chapter include combination: N₂ + 3H₂ → 2NH₃; decomposition: CaCO₃ → CaO + CO₂; double decomposition: NaCl + AgNO₃ → AgCl↓ + NaNO₃; displacement: Zn + 2HCl → ZnCl₂ + H₂.

**Textbook reference:** Chemistry Standard IX Part II, printed pp. 98-101.
