# Square-root bounds

If p² < n < q², then p < √n < q for nonnegative p,q. Refine with decimal candidates, comparing their squares; report an approximation at the precision supported by the final interval.

**Textbook reference:** Mathematics Standard IX Part I, printed pp. 20-27.
