# Linear system by elimination

For a₁x+b₁y=c₁ and a₂x+b₂y=c₂, multiply equations as needed so one variable has opposite coefficients, add to eliminate it, solve, then substitute back. Check both original equations.

**Textbook reference:** Mathematics Standard IX Part I, printed pp. 7-18.
