# Absolute Value, Distance and Midpoint

The absolute value |x| is the distance of x from zero. Distance between points a and b on a number line is |a−b|. The midpoint coordinate is (a+b)/2. These definitions apply to rational and irrational coordinates.

**Textbook reference:** Mathematics Standard IX Part II, printed pp. 165-176.
