# Chapter 3 — Let’s Develop Software: Assessment and Activities

**Standard IX · ICT · printed pp. 38–47**

## Practice embedded in the chapter

- Observe the supplied alarm-clock application and describe what its components do (pp. 38–39).
- Plan and assemble the clock interface; align each hand’s pivot point to the centre of the dial (pp. 39–41).
- Use the computer-time blocks to move the hands, then collect an alarm time with input blocks and store it in variables (pp. 41–44).
- Test the alarm condition and add a sound; create the short Python animation (pp. 44–46).

## “Let’s Assess”

The questions ask how PictoBlox layer-order commands can bring a pigeon sprite in front of a tree and which time-dependent direction expression moves an Earth sprite counter-clockwise by 5° per second (p. 47). The prompts are recorded here without copying the answer choices.

## Extended activities

1. Add bells to the clock and make them move when the alarm sounds.
2. Adapt the alarm clock to operate automatically at regular intervals without taking input.
