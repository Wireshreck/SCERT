# AI Models and Pattern Recognition

An AI system learns patterns from data and uses them to make predictions or decisions. The chapter presents three stages: **data collection**, **pattern recognition**, and **decision making**. In its forest-camera example, images of animals are collected; a trained model distinguishes tigers, elephants, and deer; the system can then count or identify listed animals (printed pp. 8–9; Table 6.1, p. 9).

An **AI model** is the trained program that analyses data for a particular task. The book explains that a wildlife model is trained on many animal images, while a language model is trained on large amounts of text. Learning from new data can improve a model, but outputs still need checking (pp. 9, 17–18).

## Example

Forest monitoring combines cameras or drone sensors with image analysis to observe animal movement and potentially alert people when animals cross a boundary. This illustrates data collection feeding pattern recognition and then a useful action.
