# Prompt Engineering

A **prompt** is the sentence or question supplied to an NLP system to obtain a response. The textbook’s examples show that a more precise prompt can guide a more useful response. It recommends being clear and specific, making the intended persona or audience clear, giving background context, including examples where helpful, and testing and refining the prompt if the result is unsuitable (printed pp. 11–14).

## Example

Instead of a broad request about history, specify a task such as explaining the causes of World War II. For a learner-facing explanation, specify the audience and the aspects to cover. The book demonstrates this by asking for photosynthesis and its light and dark phases to be explained as a high-school teacher would explain them (pp. 12–13).

Prompting affects output, but does not guarantee correctness. Verify generated information and cite AI assistance honestly (pp. 17–18).
