# Chapter 2 — Styles to Get it All in Style: Assessment and Activities

**Standard IX · ICT · printed pp. 25, 27–29, 31–36**

## Practice embedded in the chapter

- Complete the word-processing formatting table (p. 25).
- Apply `Heading 1`, observe its formatting, and use Fill Format Mode to style multiple headings (pp. 27–29).
- Modify an existing style and design two new styles for main headings and subheadings (pp. 30–32).
- Prepare footnotes and endnotes, then design the folklore encyclopedia with page elements and an automatic table of contents (pp. 32–36).

## “Let’s Assess”

Two questions ask learners to infer how changing `Heading 1` affects a seminar report and identify the heading level to use for main table-of-contents entries. The questions are on printed p. 36; this note records the tested ideas without copying answer choices.

## Extended activities

1. Create and apply a paragraph style named `MyParaStyle` throughout the folklore encyclopedia.
2. Prepare a class magazine with styles and a table of contents listing article categories and titles.
3. Make a short biographical book about thinkers of the sixth century BCE; include a table of contents and a footnote (p. 36).
