# Counting and Filtering Spreadsheet Data

**Standard IX · ICT · Chapter 4 · printed pp. 53–55**

`COUNTIF` counts cells in a range that satisfy a specified criterion. After the state rows have been classified, it can count how many belong to each population-density group. In the example, a range of classification cells and a criterion cell containing a group name are supplied to the function.

**AutoFilter** displays only rows that meet a selected condition. The chapter applies it to the Classification heading and selects “Very High Density” so that only matching state rows remain visible. More specific conditions can also be set with Calc’s Standard Filter.

These tools answer different questions: COUNTIF summarizes how many records meet a condition; a filter displays the records themselves.
