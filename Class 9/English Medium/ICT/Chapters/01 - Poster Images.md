# Chapter 1 — Poster Images

**Standard IX · English Medium · ICT · printed pp. 7–22**

Sarah and her friends prepare a Fruit Festival poster for the school Environmental Club. The chapter uses that practical design task to teach a GIMP workflow: build a canvas, keep visual elements editable on separate layers, remove and refine image backgrounds, arrange images, add text and effects, create shapes, save an editable project, and export a shareable image.

## Main ideas and workflow

1. Create a 600 × 400 pixel canvas and choose an appropriate background colour or gradient (pp. 8–11).
2. Bring in fruit and bottle images, select the intended foreground, and remove unwanted background pixels. The Fuzzy Select tool uses a threshold to include similar neighbouring colours; the Paths tool outlines a more controlled object selection (pp. 12–14, 17).
3. Place each object or design element on its own named layer. Use Scale to resize and Move to position; adjust brightness and contrast when needed (pp. 9–10, 14–17).
4. Add a second bottle by duplicating its layer. Add poster text with the Text tool and style it to support the message (pp. 18–19).
5. Add depth with a duplicate black text layer, layer ordering, and Gaussian Blur; use GIMP’s Drop Shadow effect for an image (p. 19).
6. Make a coloured label shape with a selection tool and Bucket Fill or Gradient. Save the layered project, then export a copy as JPEG, PNG, TIFF, or another suitable image format (pp. 20–21).

The sample design (Figure 1.16, p. 20) combines a blue field, fruit and bottle imagery, the title “FRUIT FEST,” a short slogan, and an identifying footer. Its visual hierarchy illustrates the chapter’s point that image, colour, message, and arrangement work together for communication.

## Key terminology

- **Image editing:** modifying an image with software to improve it or add/remove elements (p. 7).
- **Pixel:** a basic unit of a digital image; the term abbreviates “picture element” (p. 8).
- **Layer:** a transparent sheet holding a separate image element, allowing that element to be edited independently (p. 10).
- **RGBA:** red, green, and blue colour channels plus an alpha channel, which controls transparency/opacity (p. 14).
- **Threshold:** the Fuzzy Select setting that controls how much similar colour from a region is included (p. 13).

## Practice and assessment

The chapter asks learners to identify poster components; compare GIMP tools with previously learned Krita tools; complete selection-tool and layer tables; remove an image background; compose and improve the poster; and export it. The end questions check the XCF project format, Scale tool use, and why moving a pasted image may also move the background. Extended activities connect poster design to Biology’s “Digestion and Transport of Nutrients,” an Environmental Club diary cover, and Social Science’s Gupta-period material.
