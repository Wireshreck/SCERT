# Chapter 2 — Styles to Get it All in Style

**Standard IX · English Medium · ICT · printed pp. 24–36**

Anu and her friends prepare a folklore encyclopedia. The chapter shows how document styles make a long publication consistent and easier to maintain. Rather than formatting each heading or paragraph separately, a writer applies a named style and changes the style definition when the design needs revision. This structure also supports an automatically generated table of contents.

## Content and methods

- **OCR input (p. 24):** Optical Character Recognition converts character shapes in an image or scanned document into editable text. The example uses gImageReader and identifies Tesseract OCR, GOCR, and EasyOCR as OCR software.
- **Consistent document design (pp. 25–26):** Writer styles are predefined formatting features for headings, paragraphs, and pages. The book begins with an existing `Heading 1` style and a supplied `sample.ott` template.
- **Apply and reuse styles (pp. 27–29):** Choose a heading and apply `Heading 1`; use Fill Format Mode to apply a style to multiple headings. Press Escape to leave Fill Format Mode.
- **Modify and create styles (pp. 30–32):** Editing a style updates text that uses it. The example changes Heading 1’s font family, size, colour, and alignment. Learners then plan and create custom heading styles, with a style for headings and another for subheadings.
- **Footnotes and endnotes (pp. 32–33):** Add a note marker at a term and type its explanation at the page foot (footnote) or at the end of the document (endnote).
- **Automatic table of contents (pp. 34–36):** Insert a table of contents based on heading styles. The generated entries link to their locations; a right-click menu can update or edit the table.

The chapter also introduces LaTeX as a tool for scientific and mathematical publishing and Scribus as open-source desktop-publishing software (pp. 31, 34). It concludes with a class-magazine and short-biography publishing activity.

## Important relationships

Heading styles provide structure that the table-of-contents generator can recognize. If the heading hierarchy is correct, the generated contents can include main headings, subheadings, and page navigation. Since the contents derive from styles, changing a style preserves consistent appearance across the document.

## Assessment and activities

The end questions ask what happens when Heading 1’s colour is changed and which heading level should be inherited for main entries in a table of contents (printed p. 36). Extended activities are to create and apply a paragraph style, prepare a class magazine with styles and a table of contents, and prepare a short biographical book about sixth-century BCE thinkers with a contents page and footnote.
