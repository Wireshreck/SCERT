# Chapter 9 — Creating a Webpage

**Standard IX · English Medium · ICT · printed pp. 49–59**

The chapter builds a simple school website page for a fruit festival. It explains how a browser requests a page from a server, introduces URLs and HTML, and guides learners through creating a local HTML file with headings, a background colour, an image, formatted text, a table, and a video. The illustrated school webpage and source-code figures show how markup is rendered by a browser.

## Topics

- [[../Concepts/Webpages, URLs and Browsers]] — webpage and server, URL parts, browser role (pp. 49–50).
- [[../Concepts/HTML Structure and Elements]] — tags, opening and closing elements, head/title/body and headings (pp. 51–53).
- [[../Concepts/HTML Attributes, Images and Presentation]] — attributes, colour codes, image source and size, text formatting (pp. 54–56).
- [[../Concepts/HTML Tables and Embedded Video]] — table, row, header and cell elements; video source and controls (pp. 57–59).

## Activities and assessment

Learners inspect a sample page’s source, create `schoolMain.html`, add school details and headings, experiment with background colours and image attributes, format text, build a fruit-festival price table, and add a video. Assessment asks for tag purposes and which image attribute identifies the file; the extended task is a Little KITES Club webpage (printed pp. 50–59). See [[../Exercises/Chapter 09 - Creating a Webpage]].
