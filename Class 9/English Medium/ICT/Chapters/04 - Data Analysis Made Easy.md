# Chapter 4 — Data Analysis Made Easy

**Standard IX · English Medium · ICT · printed pp. 48–57**

This chapter analyses a spreadsheet of state-level 2011 Census figures using LibreOffice Calc. It turns raw population and land-area values into useful information through calculation, categorization, counting, filtering, and sheet protection. Its social-science context links regional population density with the distribution of resources and opportunities.

## Analysis workflow

1. Inspect the Census table and distinguish raw data from meaningful information (p. 49).
2. Calculate population density as population divided by land area; enter a formula for one state and use the fill handle for others. Round displayed values to two decimal places (pp. 50–51).
3. Classify each density using a criteria table and Calc’s LOOKUP function (pp. 51–53).
4. Use COUNTIF to count how many rows meet a category criterion (pp. 53–54).
5. Use AutoFilter to display rows in a selected category, such as very high density (p. 55).
6. Protect the sheet with a password to prevent unauthorized editing while retaining the ability to view the data (p. 56).

The chapter’s five density categories are: below 100, very low; 100 to less than 200, low; 200 to less than 400, moderate; 400 to less than 800, high; and 800 or above, very high (Table 4.1, p. 51). The table and charts use a state-level Census dataset with columns for population, area, population density, sex ratio, and literacy (Figure 4.1, p. 49).
