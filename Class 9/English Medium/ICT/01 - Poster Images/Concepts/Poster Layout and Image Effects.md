# Poster Layout and Image Effects

**Standard IX · ICT · Chapter 1 · printed pp. 7, 10–11, 15–20**

A poster communicates through the coordinated choice and arrangement of text, images, and background. The chapter’s “Fruit Fest” example first creates a two-colour gradient, then positions cut-out fruit and bottles, adjusts image size and brightness/contrast, and adds a prominent title, slogan, and footer.

The Move tool changes an element’s position; Scale changes its dimensions. The chapter also uses a Paths selection to isolate a bottle, layer duplication to repeat it, text-layer ordering and Gaussian Blur to create a title shadow, and a Drop Shadow filter for a bottle. Rectangle or ellipse selections can create filled shapes for a message label. Keeping design elements on separate layers supports later adjustments.

**Design principle from the example:** size and placement establish emphasis, while a short slogan and contrasting text/colour make the central message easier to notice. Figure 1.16 (p. 20) demonstrates these elements together.
