# HTML Attributes, Images and Presentation

An **attribute** adds settings to an HTML tag and is written in its opening tag (printed p. 54). The chapter uses a `bgcolor` attribute with `<body>` and gives hexadecimal colour codes made from red, green, and blue components. The table includes sample codes such as `#ff0000`, `#00ff00`, `#000000`, and `#ffffff` (p. 54).

The `<img>` tag links an image file to the page. Its `src` attribute names the image, while `height` and `width` set its display size; the referenced image should be saved in the same folder as the HTML file in this activity (p. 55). Other examples format text with `<font>` attributes for colour, face, and size, plus `<br>`, `<b>`, `<i>`, and `<u>` (pp. 56–57).
