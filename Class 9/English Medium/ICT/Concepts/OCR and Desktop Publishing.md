# OCR and Desktop Publishing

**Standard IX · ICT · Chapter 2 · printed pp. 24, 31, 34**

**Optical Character Recognition (OCR)** recognizes characters in an image or scanned document and converts them into text. The chapter demonstrates loading an image into gImageReader, selecting the text language, running recognition, and saving or copying the recognized text. It names Tesseract OCR, GOCR, and EasyOCR as examples of OCR software.

The chapter’s publishing context also introduces **LaTeX** for scientific and mathematical documents and **Scribus** for page layout and desktop publishing. These tools serve different tasks: OCR captures text from an image; word-processing styles structure and format text; desktop-publishing software helps arrange publication pages.
