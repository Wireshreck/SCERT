# Block Coding and Text-based Programming

**Standard IX · ICT · Chapter 3 · printed pp. 38, 45–46**

Block programming builds a program by dragging and joining visual instruction blocks. This reduces the need to memorise the written form of commands and helps learners focus on their order and logic. PictoBlox is used for the chapter’s alarm project.

Text-based programming writes instructions in a programming language such as Python, Java, or C++. The chapter shifts to Python for a small character animation and defines **syntax** as the correct structure of code. In Python, indentation and symbols are part of that structure, so incorrect syntax can prevent a program from running.

The two approaches express instructions in different forms; both require a clear sequence of operations and conditions.
