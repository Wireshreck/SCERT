# Interface, Sprites and Pivot Points

**Standard IX · ICT · Chapter 3 · printed pp. 39–41**

An application interface is the visible arrangement of components with which a user interacts. In the alarm-clock project, the stage holds a dial, hands, and an alarm button. Each component is a sprite with its own role and code. The dial acts as the visual background; the hands are positioned above it.

A sprite’s **pivot point** is its rotation centre. The clock hands must have their pivot points aligned at the centre of the dial; otherwise, turning them will not follow the clock face correctly. When sprites overlap, a front/back layer command changes their visual order.

This separates the design work (assemble and position the interface) from the programming work (give each component instructions), making the project easier to construct and debug.
