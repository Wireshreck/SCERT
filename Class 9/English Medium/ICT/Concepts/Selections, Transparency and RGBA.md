# Selections, Transparency and RGBA

**Standard IX · ICT · Chapter 1 · printed pp. 12–14, 17**

Selections constrain an edit to a chosen area. The chapter introduces Rectangle Select, Ellipse Select, Free Select, and Fuzzy Select. Fuzzy Select groups similar neighbouring colours according to a threshold, which can help isolate a foreground object from a plain background. For a more controlled outline, the Paths tool places points around an object and turns the path into a selection.

Deleting a selected background only produces transparency when the image layer has an alpha channel. An RGB image without alpha must first have an alpha channel added from the layer menu. RGBA means red, green, blue, and alpha; alpha controls transparency or opacity. The selected fruit or bottle can then be copied and pasted as a new layer on the poster canvas.

**Careful selection matters:** a threshold that is too broad may select parts of the subject; a narrow or detailed outline may need a different selection method. The textbook’s fruit workflow uses Fuzzy Select, while its bottle example uses Paths (pp. 13, 17).
