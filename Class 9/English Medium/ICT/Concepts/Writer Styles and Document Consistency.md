# Writer Styles and Document Consistency

**Standard IX · ICT · Chapter 2 · printed pp. 25–32**

A style is a named set of predefined formatting features for headings, paragraphs, and pages. Applying the same style to corresponding parts of a long document gives them a consistent appearance. It also makes later revision efficient: modify the style once and Writer updates the document parts that use it.

The chapter applies `Heading 1` to main headings, uses Fill Format Mode to apply that style repeatedly, and then modifies the style through its formatting options. It also has learners create named styles for headings and subheadings, choosing a suitable parent heading level in the “Inherit from” setting.

**Example:** changing the font colour of `Heading 1` changes all headings using that style, rather than only the one heading first selected. This is also the principle tested in the end-of-chapter question.
