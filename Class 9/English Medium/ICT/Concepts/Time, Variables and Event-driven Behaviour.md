# Time, Variables and Event-driven Behaviour

**Standard IX · ICT · Chapter 3 · printed pp. 42–44**

PictoBlox’s sensing blocks can read the computer’s current hour, minute, or second. A project can use a button click to ask the learner for an alarm hour and minute; variables hold those responses while the program checks them against the current time. When both values match, the program plays the alarm sound.

A **variable** stores information used by a program. In this project, `Hour` and `Minute` hold the entered alarm time. The program’s behaviour responds to events such as clicking the flag or alarm button, and to a condition becoming true when the entered and current times agree.

The same design can support a water bell: schedule reminders and play a sound at the chosen times. The chapter asks learners to adapt the clock to work repeatedly at regular intervals (p. 47).
