# HTML Structure and Elements

**HTML** (HyperText Markup Language) is a markup language whose instructions tell a browser how to display webpage content (printed pp. 51–52). Tags are written in angle brackets. A tag with its enclosed content forms an HTML element; many elements have an opening and closing tag (p. 52).

The illustrated basic document begins with `<html>` and ends with `</html>`. The `<head>` contains page metadata, including `<title>`; `<body>` contains visible content. Headings use `<h1>` through `<h6>`, and `<p>` marks paragraphs (pp. 52–54). The exercise asks learners to inspect a sample page’s source and complete a tag-usage table.

## Example

The textbook creates `schoolMain.html` in a text editor, saves it locally, opens it in a browser, then returns to the editor to add school details and inspect the rendered result (p. 53).
