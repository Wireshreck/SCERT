# Network Protocols and DHCP

A **protocol** is a shared set of rules that lets devices communicate across different operating systems and network types (printed pp. 69–70). The chapter’s examples are:

- **TCP/IP:** standard rules for exchanging information over networks and the Internet.
- **DHCP:** automatically assigns acceptable temporary IP addresses to devices on a LAN.
- **SSH:** secure remote login and computer operation; the activity also uses it to access files.
- **HTTP:** rules used to transfer webpages and related information.
- **FTP:** protocol for transferring files between computers.

Protocols let different devices interoperate by following common rules, much as road users follow traffic signs and regulations.
