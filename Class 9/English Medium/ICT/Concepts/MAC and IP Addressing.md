# MAC and IP Addressing

A **MAC address** identifies a network interface and is assigned by its manufacturer. The chapter shows a six-pair hexadecimal form and explains that digits 0–9 and letters A–F are used (printed pp. 67–68). A **number system** with digits 0 and 1 is binary; hexadecimal uses sixteen symbols (0–9, A–F), making it useful for compact identifiers (p. 68).

An **IP address** identifies a device on a network. The chapter focuses on IPv4, written as four dot-separated numbers, each from 0 through 255; its example is `192.168.1.1` (p. 69). A LAN may assign addresses automatically using DHCP or manually as static addresses. The illustrated lab example keeps the network prefix and changes the host part, with network settings for netmask, gateway, and DNS (pp. 70–73).
