# Native Project Files and Export

**Standard IX · ICT · Chapter 1 · printed pp. 11, 21–22**

GIMP’s **XCF** format is its project format. Saving the working poster as XCF preserves editing features such as layers and transparency. When an image is needed in another document or for sharing, use **File → Export** and choose an output image format such as JPEG, PNG, or TIFF.

The project file and exported image serve different purposes: XCF retains the editable construction; an exported image is a convenient finished visual. The chapter asks learners to save during work and export the completed poster (p. 21).
