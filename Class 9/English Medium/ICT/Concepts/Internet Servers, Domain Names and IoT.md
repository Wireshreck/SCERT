# Internet Servers, Domain Names and IoT

The **Internet** is described as a large-scale network formed by connecting smaller networks worldwide. Servers are computers configured to store and provide requested data and services; websites are stored on servers (printed pp. 75–76).

A website can be reached by its server’s IP address, but a **domain name** is easier to remember. The example compares a numerical address with `https://cusat.ac.in` and describes software translating the name to the IP address (p. 76).

The **Internet of Things (IoT)** is the connection of network-enabled devices that can be controlled remotely. The textbook examples include smart televisions, refrigerators, washing machines, bulbs, and fans; a microprocessor enables these devices to connect to networks (p. 77).
