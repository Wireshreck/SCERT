# HTML Tables and Embedded Video

The chapter uses `<table>...</table>` to create a fruit-festival product catalogue. Within it, `<tr>` defines a row, `<th>` a header cell, and `<td>` a data cell (printed pp. 57–58). The example has columns for item, description, and price and rows for jackfruit jam, mango squash, and tapioca (Table 9.5, p. 57; Fig. 9.6, p. 58). It also notes that tables can arrange a page layout, with text, images, and video placed in rows and columns (p. 58).

To include a video, the example uses `<video>` with width, height, and controls, and a nested `<source>` with a filename and media type. The learner task inserts `fruits.mp4` from the activity folder (pp. 58–59).
