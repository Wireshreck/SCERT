# Charts and Infographics

A chart can present analysed data in a presentation. The chapter compares a heart-risk-factor table with a bar chart, then with an infographic that combines the same analysis with colour, shapes, brief labels, and a heart image (printed pp. 42–44; Figs. 8.10–8.11). It defines an infographic as “information graphics”: a clear, simple, engaging way to communicate complex information using images, charts, and minimal text (p. 44).

In Impress, the illustrated workflow opens the Gallery, selects a diagram, edits its text, resizes shapes, adds a title and image, and uses Arrange controls to manage overlaps (pp. 44–46). The chapter also asks learners to create an infographic from regional internet-penetration percentages (p. 48).
