# Chapter 1 — Poster Images: Assessment and Activities

**Standard IX · ICT · printed pp. 8–9, 12, 17, 21–22**

## Practice embedded in the chapter

- Identify the message, images, and other elements in the sample poster (pp. 7–8).
- Compare GIMP tools with previously learned Krita tools; complete the common-tool table (p. 9).
- Identify GIMP selection tools, shortcuts, and uses (p. 12).
- Record which poster elements belong on each layer (p. 17).
- Create the sample poster and export it in an appropriate image format (pp. 18–21).

## “Let’s Assess”

The chapter asks learners to reason about why the background can move together with an image when using Move, identify GIMP’s project file format, and select the tool used to resize an image. The questions are on printed pp. 21–22; these notes preserve the prompts rather than reproducing answer choices.

## Extended activities

1. Make a GIMP poster for an awareness class on “Bad Habits and Heart Health,” using Biology’s “Digestion and Transport of Nutrients” chapter (p. 22; connect to [[../../Biology/Chapters/02 - Digestion and Transport of Nutrients]]).
2. Design a cover page for an Environmental Club members’ diary (p. 22).
3. Design a digital-album cover featuring temples and cave paintings from the Gupta period, linking it to the Social Science chapter “Land Grant System and Indian Society” (p. 22; exact book/chapter link to be added after reading that textbook).
