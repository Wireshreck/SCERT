# Chapter 9 — Activities and Assessment

**Printed pp. 50–59.** Activities are summarized; no answer key is invented.

- Open the supplied school webpage, inspect its source, and identify headings, subheadings, content, and images (pp. 50–51).
- Create and save a basic HTML file, open it in the browser, and compare the rendered page with its markup (pp. 52–53).
- Add school headings and subheadings, set a readable background colour, and explore the supplied hexadecimal colour examples (p. 54).
- Insert `juice.png` using an image source and size attributes; complete the attribute table (p. 55).
- Format the page’s text, add a fruit-festival product table using header, row and data-cell tags, then add the supplied video (pp. 56–59).
- Assessment: complete a tag-purpose table and identify which part of an image tag must change to select another image (p. 59).
- Extended activity: create a webpage for the school’s Little KITES IT Club (p. 59).
