# Chapter 6 — Activities and Assessment

**Printed pp. 10–19.** These are the chapter’s learner tasks, summarized without supplying unsupported answers.

- Compare how data collection, pattern recognition, and decision making work in the forest-camera example (p. 9).
- Add familiar NLP systems to the examples table (p. 10).
- Compare broad and increasingly specific prompts about photosynthesis, then refine a prompt for a high-school audience (pp. 11–13).
- Prepare a story about a bookseller and fisherman and a 20-line poem about Kerala’s scenery using NLP (p. 14).
- Generate an image of a girl planting a tree for a poster; inspect whether it matches the prompt and revise if needed (pp. 14–16).
- Complete a table of AI systems for preparing images, videos, 3D models, text, and translations (p. 16).
- Consider AI-supported doubt answering, simplifying explanations, and language learning, while continuing to develop personal creative skills (pp. 16–17).
- Assessment: identify which option is not a responsible-AI principle and select the example that best describes an AI agent (p. 19).
- Follow-up: use NLP to prepare a table of Kerala Chief Ministers and their tenures (p. 19); generated facts should be independently checked.
