# Chapter 10 — Activities and Assessment

**Printed pp. 60–78; PDF includes civic appendices on pp. 73–74 and 82–83.** Activity summary only; no answer key is invented.

- Identify communication media and devices in the network diagram; inspect UTP pairs, ports, RJ45 connectors, hub/switch roles, and networked peripherals (pp. 60–65).
- Classify example networks as LAN, WAN, or PAN and compare Wi-Fi with Bluetooth (pp. 65–67).
- Locate the computer’s MAC address and distinguish hexadecimal and binary notation (pp. 67–68).
- Find device IP addresses; connect through Wi-Fi, examine DHCP-assigned settings, and practise a static address in the supervised lab activity (pp. 69–73).
- Test a connection with `ping`, transfer a file over SSH, and share a screen using VNC after accepting the connection request (pp. 73–75).
- Compare accessing a website by IP address and domain name; explore the IoT device examples (pp. 75–77).
- Assessment checks valid IPv4 values, common network-device roles, and which item is not an IoT device (pp. 77–78).
- Follow-up: use the lab’s network printer and scanner, and prepare a seminar on network history from the diagram (p. 78).
