# Chapter 4 — Data Analysis Made Easy: Assessment and Activities

**Standard IX · ICT · printed pp. 49–57**

## Practice embedded in the chapter

- Inspect the Census spreadsheet, identify the information in its columns, and note its rows and columns (p. 49).
- Calculate population density and fill the formula down the state list (p. 50).
- Categorize state densities with a named LOOKUP criteria table (pp. 51–53).
- Use COUNTIF to count states by category and AutoFilter to display selected rows (pp. 53–55).
- Protect the worksheet and investigate which edits remain possible (p. 56).

## “Let’s Assess”

Questions ask learners to state what AutoFilter displays, what COUNTIF counts, and how LOOKUP relates a value to a corresponding category (pp. 56–57). This note preserves the concepts tested rather than copying the answer options.

## Extended activities

1. Use the supplied Census workbook to count states with literacy above 90% and below 70%.
2. Build a school arts-festival score sheet that assigns grades from criteria.
3. Build a student score sheet, use a lookup table to assign grades, and protect the sheet. The textbook’s example bands are below 40 → D, 40–59 → C, 60–79 → B, and above 80 → A (p. 57).
