# Network Utilities and Remote Access

The chapter’s computer-lab workflow connects a laptop to Wi-Fi, obtains an address through DHCP, and finds that IP address in network settings (printed pp. 70–72). It then describes static addressing for predictable lab access and file transfer (pp. 72–73).

To check reachability, a learner enters `ping` followed by another device’s IP address; returned data-exchange messages indicate a working connection (p. 74). To access files over SSH, the activity uses the remote computer’s address and credentials. For screen sharing, it enables Remote Desktop and the legacy VNC option on the source computer, then uses Remmina/VNC from the viewing computer; the source user accepts the connection. The text says this VNC activity does not require an Internet connection (pp. 74–75).
