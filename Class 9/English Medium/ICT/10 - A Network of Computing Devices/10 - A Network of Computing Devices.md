# Chapter 10 — A Network of Computing Devices

**Standard IX · English Medium · ICT · printed pp. 60–78**

The chapter explains networks through a road-system analogy, then develops the physical links, devices, addressing, and protocols that let computers exchange information. It moves from UTP/fibre/wireless links and switches to LAN/WAN/PAN, MAC and IP addresses, DHCP and common protocols, Wi-Fi setup, static addressing, ping, SSH file access, VNC screen sharing, Internet servers, domain names, and IoT. Figures include a labelled network diagram, cable and port images, network devices, interface screenshots, address settings, server racks, and a historical network timeline.

## Concepts

- [[Concepts/Network Media and Devices]] — fibre, copper, wireless, converters, UTP/RJ45, hubs, switches and routers (pp. 61–65).
- [[Concepts/Network Types and Resource Sharing]] — sharing files, Internet, printers and screens; LAN, WAN, PAN, Wi-Fi and Bluetooth (pp. 62–66).
- [[Concepts/MAC and IP Addressing]] — hardware identity, IPv4 ranges, subnet examples and static/dynamic addresses (pp. 67–73).
- [[Concepts/Network Protocols and DHCP]] — shared rules and the roles of DHCP, TCP/IP, SSH, HTTP and FTP (pp. 69–70).
- [[Concepts/Network Utilities and Remote Access]] — Wi-Fi connection, address discovery, ping, SSH file transfer, and VNC screen sharing (pp. 70–75).
- [[Concepts/Internet Servers, Domain Names and IoT]] — Internet as interconnected networks, server services, domain names, and connected smart devices (pp. 75–78).

## Learning activities and assessment

Activities include identifying devices in a diagram, classifying LAN/WAN/PAN, reading MAC/IP details, assigning a static address in the lab, testing reachability with `ping`, transferring files using SSH, and sharing a screen through VNC. The closing tasks use a network printer/scanner and prepare a seminar on network history. Assessment checks valid IPv4 syntax, network-device roles, and IoT examples (pp. 64–78).
