# Kalzium and Periodic Table Exploration

Kalzium is presented as interactive chemistry software based on the periodic table. Selecting an element opens data such as atomic number, mass, electron configuration, physical and chemical properties, history, uses, isotopes and a shell model (printed pp. 25–27; Figs. 7.4–7.7). The sodium diagram represents shells as circles and electrons as dots (p. 27).

Learners use groups and periods to locate elements and connect outer-shell electrons with chemical properties (pp. 28–29). Kalzium’s schemes recolour groups, families, states of matter, and iconic views; its search field locates elements by name (pp. 29–31). Tables on pp. 27–31 ask learners to compile element symbols, atomic numbers, groups, periods, electron configurations, discovery years, families, and uses.
