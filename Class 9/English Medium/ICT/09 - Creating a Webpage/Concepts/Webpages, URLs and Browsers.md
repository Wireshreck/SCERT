# Webpages, URLs and Browsers

A webpage is a digital page viewed on a computer, phone, or tablet. The chapter describes it as a file stored on a server: a device requests the page and the server returns it (printed pp. 49–50).

A **URL** (Uniform Resource Locator) is the web address identifying where a page is stored. The example `https://www.schoolwiki.in` is broken into the access scheme (`https://`), server subdomain (`www`), and domain name (`schoolwiki.in`) (p. 50). A **web browser** retrieves the addressed page and interprets its instructions to display text and images. Examples in the book include Firefox, Chromium, Chrome, Safari, and Edge (p. 50).
